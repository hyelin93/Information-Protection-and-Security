# 요구사항 ID 목록

커밋 메시지와 PR 제목의 `[요구사항ID]`는 이 표를 기준으로 쓴다. 상세 설명, 담당, 진행 상태는 구글 시트 요구사항 명세서와 WBS에서 관리하고, ID가 바뀌면 이 파일도 같이 고친다.

## 기능 요구사항

| ID | 요구사항 | 담당 | 우선순위 |
| --- | --- | --- | --- |
| FR-01 | 취약 데모 페이지 (정상 1, 벡터별 3, 혼합 1) | 김나연 | 필수 |
| FR-02 | 데모 서버 (FastAPI, 127.0.0.1) | 김나연 | 필수 |
| FR-03 | 가짜 수신 엔드포인트 `POST /collect` | 김나연 | 필수 |
| FR-04 | AI 에이전트 (페이지 읽기, 요약, 도구 호출) | 김나연 | 필수 |
| FR-05 | 방화벽 ON/OFF | 김나연, 김혜린 | 필수 |
| FR-06 | 콘텐츠 추출과 조각 나누기 | 김혜린 | 필수 |
| FR-07 | 위험 패턴 탐지 (규칙 4종 + 은닉 가산) | 김혜린 | 필수 |
| FR-08 | 위험 점수 (0~100) | 김혜린 | 필수 |
| FR-09 | 3단계 판정 (통과, 격리, 차단) | 김혜린 | 필수 |
| FR-10 | 판정 근거 (신호 목록, 명령 요약) | 김혜린 | 필수 |
| FR-11 | 감사 로그 (JSON Lines) | 김혜린 | 필수 |
| FR-12 | 설정 파일 (임계값, 가중치, ON/OFF) | 김혜린 | 필수 |
| FR-13 | 최소 대시보드 | 김나연 | 필수 |
| FR-14 | 평가 스크립트 (탐지율, 오탐율) | 김혜린 | 필수 |
| FR-15 | 평가 데이터셋 (공격 24, 정상 20) | 김나연, 공동 | 필수 |
| FR-16 | 확장 벡터 (zero-width, meta) | 미정 | 선택 |
| FR-17 | 브라우저 확장 팝업 | 미정 | 선택 |

## 비기능 요구사항

| ID | 요구사항 |
| --- | --- |
| NFR-01 | 로컬 한정 (127.0.0.1 바인딩, 외부 전송 거부, 가짜 값만 사용) |
| NFR-02 | 비밀값 관리 (`.env`만 사용, 커밋 금지) |
| NFR-03 | 설명 가능성 (통과가 아닌 판정에 근거 1개 이상) |
| NFR-04 | 조절 가능성 (설정 파일만 고쳐서 임계값, 가중치 변경) |
| NFR-05 | 결정성 (같은 입력, 같은 점수) |
| NFR-06 | 추적성 (로그 한 줄로 판정 경위 파악) |
| NFR-07 | 품질 (firewall/ 단위 테스트, 병합 전 통과) |
| NFR-08 | 성능 (검사 처리 시간 측정, 보고서 기록) |

## 요구사항이 없는 작업

초기 세팅, 회의록, 보고서처럼 기능 요구사항과 묶이지 않는 작업은 WBS 번호를 쓴다. 예) `[WBS-2.7]` 저장소 초기 세팅, `[WBS-2.12]` 중간보고서 1차
